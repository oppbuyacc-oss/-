# Wallet

Mobile-first standalone web app.

- Full-screen white iPhone/PWA layout
- Main American Express card image embedded in the HTML
- Biometric unlock using WebAuthn platform authentication on supported HTTPS origins; on Face ID-capable iPhones this can invoke the system Face ID prompt
- Information page based on the supplied reference layout
- Payment flow, reader scanning, variable payment amount, receipt and transaction history
- No user-facing "demo" wording

Important: this is a wallet-style web app, not Apple Wallet and not a real payment instrument. A real payment requires Apple's supported payment APIs/entitlements and issuer/payment-provider integration.
